# Project_Inter-shop

# Содержание проекта

 Internet-shop_1 - в пакете, в качестве хранилищ данных применяются Массивы. А для
     описания свойств и предметов используются кастомные классы Category, Product,
     Basket и User. Их объекты описывают: Category - категории товаров, 
     различаемые порядковым номером. Product[] bask1 - товары в группе "Овощи", 
     Product[] bask2 - товары в группе "Хлеб", Product[] bask3 - товары в группе 
     "Мясное". User - покупателей, количество покупаемых ими товаров и их login и 
     пароли. Данные по товарам вводятся предварительно, для оценки их использования в сочетании с подключением
     покупателей, и распределением товаров по корзинам (объектам Basket). Затем - эта информация выводится на 
     консоль, в определённой очерёдности.  
 Internet-shop_2 - в данный пакет, относительно предыдущего, добавляются классы, 
     позволяющие принять информацию с ввода, такие как Scanner, и сделать выбор 
     требуемых товаров. А также - классы пакета java.time, позволяющие учитывать 
     время обращения к данным хранилищам, и java.util, Locale и ResourceBundle, 
     позволяющие выбрать в отчёте о покупке язык вывода.        
     Предварительно - через объект нового кастомного класса Authentication поступают данные о покупателе, и также 
     указывается количество приобретаемых товаров. Затем, покупателю предлагается выбрать каталог из предоставленных 
     (в тех же вариациях, что и категории товаров), и далее - выбрать товар по его названию. Выборы проводятся с 
     применением цикличности методов for(), и условий switch(). После выбора нужного товара, если количество товаров 
     ещё не заполнилось, предложение выбрать следующий товар также повторяется. После завершения выбора поступает 
     требование провести оплату по каждому товару, и после ввода вносимой величины происходит сверка данной величины 
     с требуемой, в результате чего либо поступает требование провести оплату по следующему товару, либо определяется 
     некорректность размера вносимой величины. Здесь, циклы построены на методах while() и do-while(), а условия - if-else.  
     А по завершению проведения оплаты предлагается выбрать язык отчёта, вводя  его наименование. В отчёте информация 
     о покупках выводится в порядке категорий товаров, с предварительным указанием даты проведённой покупки.  
 Internet-shop_3 - в пакете хранилища данных в массивах преобразуются в коллекции 
     в параметризованных списках. И для связи групп категорий товаров с их 
     названиями используется словарь Map goods. Кроме того, данные о покупке, 
     стоимостях приобретённых товаров, сохраняются в текстовый файл 
     File_of_report.
